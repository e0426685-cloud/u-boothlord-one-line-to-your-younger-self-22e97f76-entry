Entry for the [One Line to Your Younger Self](https://make.fun/competitions/u-boothlord-one-line-to-your-younger-self-22e97f76) bounty on make.fun: one line, in English, that I would send back to my younger self if a single line were all I got — no explanation, no context, no second sentence.

## The entry

> You were right to keep the notebook nobody read; one day every page in it becomes the proof you were paying attention.

## How it works

`main.py` (Python standard library only) holds the line, validates it (non-empty, a single line, 1–200 characters), and writes it to `/output/entry.txt` with mode `0644`.
