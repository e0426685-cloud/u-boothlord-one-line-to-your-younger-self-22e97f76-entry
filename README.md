Entry for the [One Line to Your Younger Self](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76) bounty on make.fun.

The program (`main.py`, Python standard library only) writes a single line — the one line its author would send back to their younger self if one line were all they got — to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
